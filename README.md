# 3BİTES — Web Sitesi V2

**Geliştiren:** Melike Naz Şamiloğlu  
**Proje türü:** Üniversite dersi kapsamında geliştirilen web tasarımı prototipi  
**Sürüm:** V2 — İkinci web tasarımı

## Proje hakkında

3BİTES, atıştırmalık ürün konsepti için hazırlanmış çok sayfalı bir web sitesi tasarımıdır. Bu depo, projenin ikinci web tasarım sürümünü içerir. İlk sürüm ve daha sonra üzerinde çalışılan gerçek girişim planları bu depodan ayrıdır.

## Teknolojiler

- HTML
- CSS
- Web arayüzü etkileşimleri (mevcut sayfalar kapsamında)

## Sayfalar

- `index.html` — Ana sayfa
- `magaza.html` — Mağaza arayüzü
- `urun-detay.html` — Ürün detay arayüzü
- `sepet.html` — Sepet arayüzü
- `sustainability.html` — Sürdürülebilirlik
- `contact.html` — İletişim

## Dosya yapısı

Görseller `images/` klasöründe tutulur. HTML ve CSS dosyalarındaki göreli görsel yolları bu yapıya uygun olarak korunmuştur.

## Çalıştırma

`index.html` dosyasını bir tarayıcıda açarak statik web sitesi tasarımını inceleyebilirsiniz.

## Kapsam ve sınırlamalar

Bu çalışma akademik amaçlı bir **web sitesi prototipidir**. Sayfalardaki ürün, sepet, iletişim veya alışveriş arayüzleri gerçek satış, ödeme, sipariş ya da ticari faaliyetin mevcut olduğu anlamına gelmez. Ürün içerikleri ve ticari beyanlar doğrulanmış gerçek ürün bilgileri olarak kullanılmamalıdır.
